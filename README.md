# Super-Market
初衷只是想做一个界面美化mod，可是做着做着就变成现在这样了，这是个主要由ai创建的mod，合作了e4mc模组的作者
功能：
更衣室
模组下载
资源包下载
存档下载
光影下载
皮肤下载
备份管理
独立存档模组
独立存档资源包
离线好友系统（正版账号也可用）
基岩版式联机功能（加好友-开房-即可联机）
更多细节可以自己查看源码（联机功能已混淆，闭源）
> Super Market is a client-side NeoForge quality-of-life mod: a built-in Modrinth
> marketplace for mods, packs and worlds, a fitting room for local skins and capes,
> a friends list with one-click LAN-style co-op over a private relay, per-world
> resource-pack and mod-management tools. No gameplay advantage, no cheats.
